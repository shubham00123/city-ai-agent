# 🌆 City AI Agent

An AI-powered city assistant that provides **current weather information** and **latest news** for cities in India.

## 🚀 Features

- 🌦️ Current weather information
- 📰 Latest city news
- 🤖 AI-powered responses using Groq
- 🔧 LangChain tool calling
- 🌐 OpenWeather API integration
- 🔎 Tavily web search
- 💬 Streamlit-based interface

## 🛠️ Tech Stack

- Python
- LangChain
- Groq
- OpenWeather API
- Tavily
- Streamlit

## ⚙️ How It Works

User → Streamlit UI → AI Agent → Groq LLM → Weather / News Tools → Final Response
